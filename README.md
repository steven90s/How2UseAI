# AI工具与大模型部署指南

记录各种AI工具使用方法和大模型部署步骤的文档网站。

## 内容

### AI工具
- Cursor - AI驱动的代码编辑器
- Claude Code - Anthropic的命令行AI助手
- GitHub Copilot - GitHub的AI编程助手

### 大模型部署
- Ollama - 本地大模型运行工具
- vLLM - 高性能大模型推理引擎
- LM Studio - 图形化大模型部署工具

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev

# 构建
npm run docs:build

# 预览构建结果
npm run docs:preview
```

## 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- Vue 3 - 前端框架
- Markdown - 文档编写
