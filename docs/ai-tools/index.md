# AI工具概览

这里收集了各种AI编程工具的使用指南，帮助你提高开发效率。

## 为什么使用AI工具？

AI工具可以显著提升编程效率：
- **代码补全**：智能预测你想要编写的代码
- **代码解释**：帮助理解复杂的代码逻辑
- **Bug修复**：自动识别和修复代码问题
- **文档生成**：自动生成代码注释和文档

## 工具列表

### 常用 AI 工具

| 工具 | 类型 | 特点 |
|------|------|------|
| [Cursor](/ai-tools/cursor) | 代码编辑器 | 基于VS Code，深度集成AI |
| [ChatGPT](/ai-tools/chatgpt) | 通用AI助手 | 支持网页端、移动端和 App Store 订阅 |
| [Claude Code](/ai-tools/claude-code) | CLI工具 | 命令行AI助手 |
| [GitHub Copilot](/ai-tools/copilot) | 插件 | 支持多种IDE |
| [OpenAI Codex](/ai-tools/codex) | AI 编程 Agent | 支持 Web、桌面应用、CLI、IDE 扩展和云任务 |
| [OpenCode](/ai-tools/opencode) | 开源 AI 编程 Agent | 支持终端、桌面、IDE、多 Provider 和本地模型 |

### 其他AI工具

- **Claude** - 通用AI对话助手
- **Midjourney/DALL-E** - AI图像生成
- **Whisper** - 语音转文字

## 选择建议

- **新手**：推荐从 Cursor 开始，界面友好，上手简单
- **命令行用户**：Claude Code 是很好的选择
- **开源和多模型用户**：OpenCode 适合想接入不同 Provider 或本地模型的人
- **团队协作**：GitHub Copilot 集成度高，适合团队使用
