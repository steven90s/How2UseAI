# 终端学习指南

终端（Terminal）是开发者与操作系统交互的核心工具。无论是安装软件、管理文件、运行代码，还是使用 Claude Code、Codex 等 AI 编程工具，都离不开终端操作。

## 为什么要学终端？

- **AI 工具的基础**：Claude Code、Codex CLI、OpenClaw 等都在终端中运行
- **效率更高**：批量操作、自动化脚本远比图形界面点击快
- **开发必备**：Git、npm、Docker、SSH 等开发工具都通过终端操作
- **服务器管理**：远程服务器通常只有命令行界面
