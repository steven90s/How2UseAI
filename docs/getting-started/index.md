# 入门指南

欢迎来到AI世界！本章节将帮助你了解人工智能的基础知识，从起源背景到各家模型的对比，让你快速入门。

## 为什么学习AI？

人工智能正在改变我们的工作和生活方式：

- **编程效率** - AI助手帮你写代码、调试、解释代码
- **内容创作** - AI帮你写文章、生成图片、制作视频
- **数据分析** - AI帮你分析数据、生成报告、发现洞察
- **语言翻译** - AI提供高质量的多语言翻译
- **学习加速** - AI作为私人导师帮你学习任何知识

## 快速开始

如果你想直接体验AI，可以：

1. 访问 [ChatGPT](https://chat.openai.com) 体验在线对话
2. 访问 [Claude](https://claude.ai) 体验 Anthropic 的AI助手
3. 使用 [Ollama](/llm-deployment/ollama) 在本地运行开源模型
