本文档介绍目前主流的大语言模型，帮助你了解各家产品的特点。

| 特性 | 说明 |
|------|------|

## 模型分类总览

### 按访问方式

| 类型 | 代表模型 | 特点 |
|------|----------|------|
| 商业API | GPT-4、Claude、Gemini | 能力强、付费、云端 |
| 开源可商用 | Llama、Qwen、DeepSeek | 可本地部署、可微调 |
| 开源不可商用 | 某些研究模型 | 仅限研究使用 |

### 按参数规模

| 规模 | 参数量 | 显存需求 | 适用场景 |
|------|--------|----------|----------|
| 小模型 | <10B | 8GB | 边缘设备、快速响应 |
| 中模型 | 10B-70B | 16-48GB | 本地部署、平衡性能 |
| 大模型 | >70B | 48GB+ | 服务器部署、最强能力 |

### 按应用场景

| 场景 | 推荐模型 |
|------|----------|
| 日常对话 | GPT-4o、Claude 3.5 Sonnet |
| 编程开发 | Claude 3.5 Sonnet、GPT-4o |
| 长文档处理 | Gemini 1.5 Pro、Claude 3 |
| 本地部署 | Llama 3.1、Qwen 2.5、DeepSeek |
| 中文任务 | Qwen 2.5、DeepSeek、GPT-4 |
| 成本敏感 | DeepSeek、Llama 3.1 |
