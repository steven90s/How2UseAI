## OpenAI

OpenAI 目前最新的旗舰模型，2026年3月发布。

| 特性 | 说明 |
|------|------|
| 多模态 | 支持文本、图像、音频输入 |
| 上下文 | 1M tokens（100万） |
| 计算机操作 | 原生支持计算机操作能力 |

**版本说明**：
- **GPT-5.4 Thinking** - 高级推理能力，可展示思考过程

## 模型分类总览

### 按访问方式

| 类型 | 代表模型 | 特点 |
|------|----------|------|
| 商业 API | GPT-5.4、Claude 4、Gemini 2 | 能力强、付费、云端 |
| 开源可商用 | Llama 3.3、Qwen 2.5、DeepSeek | 可本地部署、可微调 |

### 按参数规模

| 规模 | 参数量 | 显存需求 | 适用场景 |
|------|--------|----------|----------|
| 小模型 | <10B | 8GB | 边缘设备、快速响应 |
| 中模型 | 10B-70B | 16-48GB | 本地部署、平衡性能 |
| 大模型 | >70B | 48GB+ | 服务器部署、最强能力 |

### 按应用场景

| 场景 | 推荐模型 |
|------|----------|
| 日常对话 | GPT-5.4、Claude Opus 4.6 |
| 编程开发 | Claude Opus 4.6、GPT-5.4 |
| 长文档处理 | Gemini 2.0、Claude 4.6 |
| 本地部署 | Llama 3.3、Qwen 2.5、DeepSeek V4 |
| 中文任务 | Qwen 2.5、DeepSeek V4 |
| 成本敏感 | DeepSeek、本地开源模型 |
